# M3 — SFT 冷启动

状态：**验收通过**（2026-07-14，tag `m3`，两项边缘指标经用户确认接受）｜时间盒 2 天（PLAN §7，Day 6–8），实际 1 天内完成

## 批准的计划（2026-07-14，原文，不追改）

**目标**：教会 Qwen3-1.7B 可靠的 TIR 行为（M1 诊断的四类失败模式），产出**所有 RL 实验的
统一起点 checkpoint**。教师：本地 Qwen3-8B（用户确认，qa_log Q7；产量不足时
Qwen2.5-Math-7B 补 L5）。

### 1. 蒸馏轨迹生成 `sft/gen_trajectories.py`

- **准备**：下载 Qwen3-8B（~16GB）；`scripts/m1/serve_sglang.sh` 已支持 `MODEL=` 环境变量，
  直接复用；先从 5403 条训练子集中**留出 200 题作 held-out**（验收用，不参与生成）。
- **生成**：复用 M1 probe 的多轮循环基础设施（bare 风格 = 与训练格式严格一致、非 thinking、
  max_turns=4、沙箱真实执行），温度 0.7、每题 2 条，覆盖其余 ~5200 题。
- **Rejection sampling 四条件**：① verifier **严格 boxed 口径**判对；② ≥1 次成功工具调用
  （**允许含报错后恢复的轨迹**——E5 最需要的样本类型，只要最终答对）；③ 未截断；
  ④ 总响应长度 ≤3072 token（必须装进学生训练预算，同家族 tokenizer 直接量）。
- **产出**：`sft/data/sft_traces.jsonl`（chat 格式含 tool_calls）+ 分 level 产量/过滤原因
  统计（不静默丢弃）。目标 1.5k–2.5k 条。

### 2. SFT 训练 `sft/train_sft.py`

- LoRA（r=32, alpha=64），1–2 epoch（防压熵），HF Trainer + peft（新依赖 peft/accelerate，
  pin 入 requirements）。
- **工具返回 token 不计 loss**：按 verl 同款 delta tokenization 构建 labels mask
  （M2 masking 测试已摸透机制），SFT collator 附带小单测。
- 训练完 **merge adapter 成完整 checkpoint**——M4 的 verl 直接 `model.path` 指向它。
- 落盘五件套（config/ckpt/预测/metrics/摘要）。

### 3. 验收评测（也是 M1 判读的验证）

| 项 | 标准 |
|---|---|
| held-out 200 题工具格式成功率 | >90%（≥1 次调用且全部可解析执行） |
| held-out pass@1 | 显著高于零样本基线 |
| **工具增益复测** | M1 probe 原班脚本（同 500 题、同协议）测 SFT 后模型；增益转正与否都如实写入报告 01 附录 + 技术报告 |
| SFT 后分 level 通过率 | 给 M4 数据应变点供数（L3 是否饱和） |

### 4. 风险与预案

- Qwen3-8B 在 L5 产量低 → Qwen2.5-Math-7B 补（含格式转换+重执行校验）；
- SFT 后增益仍为负 → 停下报告用户（动摇 M4 前提）；
- 熵坍缩担忧 → 只 1–2 epoch，RL 阶段监控熵曲线起点。

### 不做的事

不写 RL config（M4）；不做超参扫描；不做 CoT-SFT 对照组（记为 future work）。

## 执行偏差与决策记录

| 事项 | 计划 | 实际 |
|---|---|---|
| SFT 样本构造 | delta tokenization collator | 更优方案：教师轨迹经**真实 verl ToolAgentLoop 重放**转训练样本（`sft/trace_tokenizer.py`），与 M4 rollout 逐 token 同构，附 3 项单测 |

| 数据质检 | 四条件过滤 | 追加第五条件：tool_call 参数键必须恰为 `{code}`（发现 1 条教师轨迹带多余键，会教坏调用格式且破坏重放对齐；重放侧加消费断言钉住） |

## 验收结果

| 验收项 | 标准 | 结果 |
|---|---|---|
| 工具格式成功率 | >90% | ⚠ 93.0%（500 题复测）/ 89.5%（held-out 200，边缘） |
| held-out pass@1 vs 零样本 | 显著更高 | ⚠ TIR 0.510 vs 0.491（+1.9pt，n=800 不显著）；500 题 0.704 vs 0.676（+2.8pt，p≈0.06 边缘） |
| 工具增益复测 | 如实报告 | **整体 −0.032 仍负 → 触发"停下报告用户"条款**；但单调改善（base −0.101 → 2.5k −0.056 → 6k −0.032），L5 转正 +0.030、L4 收窄至 −0.050；负增益集中在 L1–3（CoT 0.84–0.91，工具本无用武之地，且不在 RL 训练池） |
| 可靠性指标（SFT 的设计目标） | — | ✅ 工具报错率 34%→19%、截断 7.5%→5.1%、弃用工具 27%→7% |
| GRPO 前提（组内方差） | — | ✅ L3–5 混合结果占比 0.39/0.54/0.48 |

**决策（2026-07-14，用户确认）**：接受现状，**SFT-6k（`sft/checkpoints/qwen3-1.7b-sft`）
定为所有 RL 实验的统一起点**，进入 M4。判读依据：负增益集中在不在训练池的 L1–3；
训练池 L4–5 已平价/转正；剩余差距（数学能力 + 教师未覆盖的 41% L5 难题）是 on-policy RL
的工作而非 SFT 的（教师成绩单与判读见 qa_log Q8、技术报告 §5）。

## 2026-08-19 最小改进复核（追加记录）

- **更强 teacher**：固定 L3/L4/L5 = 50/50/100 题、每题 2 条的 probe 中，Qwen3-30B-A3B
  相对 Qwen3-8B 的有效轨迹产率为 52% vs 53%，题目覆盖率 69% vs 68%，L5 覆盖率
  63% vs 65%；虽工具错误率较低（10.3% vs 22.7%），但产率和关键 L5 覆盖均未改善。
  按预设门槛拒绝切换，未做 30B 全量生成。
- **Full SFT**：同一 6056 条数据做一次 full-parameter 对照（2 epoch、effective batch 32，
  固定 LR 1e-5，无调参），再按同一 held-out 200、temperature 0.6、n=4、bare TIR 协议评测。
  Full vs LoRA：TIR pass@1 0.5188 vs 0.5100，CoT pass@1 0.5900 vs 0.5725，工具错误率
  0.2654 vs 0.2013，工具弃用率 0.1150 vs 0.1050。pass@1 改善很小且工具可靠性更差，
  **拒绝切换 full SFT**。
- **最终决策不变**：保留 Qwen3-8B 教师数据和 LoRA SFT-6k checkpoint
  `sft/checkpoints/qwen3-1.7b-sft` 作为 M4 统一起点。产物见
  `sft/experiments/m3_minimal/` 与 `data/probe_heldout_full_sft/`。
