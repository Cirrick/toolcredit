**ToolCredit｜多轮工具调用大模型强化学习与信用分配**

- 基于 veRL、SGLang 与 Qwen3-1.7B 构建“数学推理 + Python 解释器”多轮工具调用强化学习管线，集成多轮 rollout、沙箱执行与数学答案验证，完成训练/评测数据去污染。

- 基于工具执行成功与返回结果利用情况探索轮级信用分配，针对训练中出现的工具重复调用与调用预算耗尽问题，通过逐轮优势分析，定位非守恒信用修正引入的隐式调用激励；设计 **token 加权零和的轮级信用再分配**，结合零方差门控与重复调用信用约束，在统一评测中大幅降低过度调用与轨迹截断比例。

**ToolCredit｜多轮工具调用大模型强化学习与信用分配**

- **训练管线**：基于 veRL、SGLang 与 Qwen3-1.7B，在单卡 GH200 上搭建数学推理与 Python 工具调用的多轮 RL 管线，串联 SFT 冷启动与 GRPO 训练；200 步 GRPO 将 MATH500 greedy pass@1 从 SFT 起点的 **59.4% 提升至 76.6%（+17.2 个百分点）**。
- **数据与训练一致性**：利用 Qwen3-8B 蒸馏与拒绝采样构建 **6,056 条工具推理轨迹**，包含 797 条报错恢复样本；通过真实 AgentLoop 重放对齐 SFT 与 rollout 的 token 序列，实现工具返回 token 的 loss masking，并完成 LoRA SFT 冷启动。
- **信用分配改进**：实现轮级优势修正，诊断非守恒修正项引入隐式调用激励的问题；设计 token 加权零和再分配，结合零方差门控及重复调用约束，使 760 题 greedy 评测中用满四次调用预算的轨迹占比由初版 **92.9% 降至 0.8%**，截断率由 **100% 降至 8.7%**；相对标准 GRPO 的准确率差异未达统计显著。
- **评测与实验诊断**：构建覆盖 MATH500、AIME24/25、GSM8K 的 **760 题固定评测集**，完成五个模型阶段共 **19,000 条评测轨迹**；采用逐题配对分析与 **10,000 次分层 bootstrap**，结合奖励塑形、loss-mask 消融区分准确率变化与工具行为偏移。
- **因果对照（M9）**：为区分"学会用工具"与"RL 提升推理"，在同起点、同数据、同配方、同 200 步下训练**无工具对照臂**（唯一变量为 prompt 中的工具 schema，resolved-config diff 精确等于 5 条预注册路径，零框架改动）；在 **15,200 条**新增评测轨迹上按预注册矩阵判读为**无差异**（Δ = −0.92pt，95% CI [−3.55, +1.71]），并将 SFT→GRPO 的 **+12.76pt** 精确分解为 **6.05pt（不再被工具拖累）+ 4.74pt（自身推理提升，CI [+2.11, +7.50]）+ 1.97pt（工具边际价值，CI 跨 0）**，据此给出"该规模下工具净收益不显著、收益集中在 MATH L4–5"的结论与后续方向。
- **算力归一化的 DAPO 动态采样消融（M10）**：在 pin 版 veRL 上以子类复制 trainer 主循环并用测试逐行 diff 约束为 8 处白名单差异，实现 DAPO 式零方差 group 过滤与同 snapshot 补采样（config diff 精确 7 路径）；训练时按累计 rollout 轨迹数自动落盘**等算力 checkpoint**，评测同时报告**有效 step 与累计 rollout 两条 x 轴**。结果：等 rollout 算力下与标准 GRPO 持平（Δ −0.39pt，95% CI [−2.89, +2.11]），多花 2.53× rollout 的终点 +5.13pt（CI [+2.63, +7.63]）；并量化出**过滤成本随策略变准单调上升**（零方差组 34%→61%，每步补采样批数 2.0→3.1）。同时通过按进程 `Pss_Anon` 分段拟合，把导致六条 200 步 run 中断的容器级 OOM 定位到单个 FSDP worker 进程（占匿名内存增长 93%）。
